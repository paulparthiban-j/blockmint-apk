# Blockmint — Android app

Download the latest app for residents and community staff:

**[⬇ Download blockmint.apk](https://github.com/paulparthiban-j/blockmint-apk/releases/latest/download/blockmint.apk)**

Or open **Get the app** from the Blockmint web console (`/download`).

## Installing
1. Open the downloaded `blockmint.apk` on your Android phone.
2. If asked, allow installing apps from your browser / file manager.
3. Sign in with your mobile number; the code is sent by SMS.

Updates install over the previous version (from build 33 onwards). If you installed a build
older than 33, uninstall it once before installing this one.

## Releases
Each release is tagged `mobile-v<version>-<build>` and carries the APK as `blockmint.apk`.
The web console's download page always serves the newest `mobile-*` release from this repository.
